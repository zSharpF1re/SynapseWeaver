Web-app for learning through an AI generated knowledge graph.

Key features:
- Each node has a title and content: text, files, urls
- Each node gets generates to-be-discovered related nodes
- Node text content can be generated through AI
- Knowledge bin endpoint to throw info to be categorized "nodified" by AI
- Smart node merging and connections

The app is obviously made to interact with AI. It solves a problem: when learning something you don't know what else to learn
It encourages extended polyhedric knowledge, made easy through a nice UX and AI automation.
